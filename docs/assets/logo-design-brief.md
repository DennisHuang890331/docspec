# ArtiSpec logo proposal / 標誌設計提案

Status: proposal for a drawing agent; the existing logo is unchanged. / 狀態：供繪圖 agent 使用的提案，尚未定稿，現有 logo 未替換。

## 品牌與概念

ArtiSpec 是用規格驅動文件與軟體工程的 CLI。它記錄負責人的決定與需求，管理工作及修改，並保存驗證證據。文件與軟體共用治理與交接，各自保留完成條件。

建議方向是「雙軌工程 A」：兩條幾何支柱組成抽象 A，代表文件與軟體；共同橫梁表示共用的規格、治理及追溯。讓圖形先成立，再用左側的折頁切角、右側的括號切角輕微暗示兩個領域。小尺寸看不清時，優先保留清楚的 A 與雙支柱結構。

風格簡潔、沉穩、有工程圖的秩序。建議深藍 `#183B56` 與青綠 `#21B6B8`，並提供單色版本。不要以 AI 大腦、機器人、齒輪、疊起來的文件或多個小圖示堆疊成 logo。

## English prompt — copy to a drawing agent

Design a new logo for **ArtiSpec**, a CLI for specification-driven engineering across documents and software. It helps AI agents work from recorded owner decisions and requirements, manage traceable changes, and retain verification evidence. Documents and software share governance and handover, while keeping separate workflows and completion conditions.

Create a restrained geometric mark built around an abstract capital **A**. Two distinct structural pillars represent the document and software domains; a shared crossbar represents specifications, governance, and traceability. Explore a subtle folded-page cut on the left and an angular bracket cut on the right, integrated into the structure rather than added as separate icons. Keep the mark simple enough to read at 24–32 pixels. If the domain hints create clutter, simplify them and preserve the strong A silhouette and connected structure.

Use flat vector-style geometry, balanced negative space, deliberate stroke weights, and clean edges. Aim for an engineering tool identity: precise, calm, and approachable. Suggested colors: deep blue **#183B56** and teal **#21B6B8**. It must also work in one color and on both light and dark backgrounds.

Provide three variations of this concept: an outlined mark, a solid mark using negative space, and a two-color mark. Show the icon alone and a horizontal icon-plus-wordmark lockup. Spell the wordmark exactly **ArtiSpec**, with capital A and S, in a clean sans-serif typeface. Keep the wordmark separate so the icon can be used alone.

Avoid robots, brains, circuit-board decoration, gears, stacked document icons, generic hexagonal tech badges, gradients, 3D effects, shadows, tiny text, and a collection of miniature symbols. Do not put a slogan inside the logo. Show the actual artwork clearly, without merchandise or device mockups.

For the selected direction, supply a transparent-background PNG at 1024×1024, a monochrome version, light/dark previews, and 32/48-pixel icon previews. If your tools support editable vector artwork, also supply SVG with separate paths; otherwise state that the output is raster. A raster image embedded in SVG is not an editable vector deliverable.

## 中文 prompt — 可直接交給繪圖 agent

請為 **ArtiSpec** 設計新 logo。這是用規格驅動文件與軟體工程的 CLI，協助 AI agent 從負責人的決定與需求出發，管理可追溯的修改，保存驗證證據。文件與軟體共用治理與交接，各自保留流程及完成條件。

以抽象大寫 **A** 為主體，用兩條不同的幾何支柱代表文件與軟體，共同橫梁表示規格、治理及追溯。可在左側融入折頁切角，右側融入程式括號的切角；兩者必須融入主體，不要另外貼兩個圖示。24–32 像素仍需辨識清楚，細節太多時優先保留 A 的輪廓與相連的雙支柱。

採平面向量風格、平衡留白、清楚線寬與乾淨邊緣，呈現精準、沉穩、容易親近的工程工具。建議深藍 **#183B56** 搭青綠 **#21B6B8**，單色及深淺背景也要成立。

先提供同一概念的三種變體：線框、實心負空間、雙色。各展示單獨圖標與橫式「圖標＋字標」。字標必須正確寫成 **ArtiSpec**，A、S 大寫，使用清楚的無襯線字體，並與圖標分開製作。

不要機器人、AI 大腦、電路裝飾、齒輪、疊文件、通用六角科技徽章、漸層、3D、陰影、小字或多個小圖示堆疊；logo 內不要放標語。直接展示圖稿，不要商品或裝置 mockup。

選定方向後提供 1024×1024 透明背景 PNG、單色版、深淺背景預覽及 32／48 像素圖標預覽。工具能輸出可編輯向量時另提供獨立路徑的 SVG；只能產生點陣圖就明示，不要把內嵌 PNG 的 SVG 當成可編輯向量。

## Review / 檢查

- 兩個領域在構圖上平衡，不讓一個領域看起來附屬於另一個。
- 縮至 32 像素與轉成單色後，主輪廓仍成立。
- 字標大小寫正確，文字與圖標都能獨立使用。
- 此提案仍需從實際圖稿選定方向，不把三種探索變體當成最終 logo。
