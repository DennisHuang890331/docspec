# 明確宣告測試的共用來源

日期：2026/10/04。狀態：同題實測新增觀察，尚未裁定或實作；不列為本輪已核定修正。

Windows 案的原測試作者修正 conftest.py 後，在重新簽收之前，19 筆簽收仍為 current。現行 test-fingerprint 追蹤測試自身與同檔共用內容，不追蹤另一個檔案的 fixture；原任務的宣告 files 也未包含 conftest。這是可核實的來源邊界，不是已證明的假完成：當時排座只有失敗證據，既有通過的 CSV 任務不使用修改的 fixture。原實作者透過 O1 交回測試作者，沒有修改測試；本案仍會重新取得真實證據。

來源是本輪案外 `independent-exam-reviews/windows-fixture-objection/before-sign-observation.json`，包含修改前後檔案指紋、實際簽收查詢、證據與任務現況。原失敗及來源審查漏查的更正另存，不能說產品已自動檢查所有 fixture。

建議沿用 tests.yaml 的每筆測試，讓測試作者明確列出會影響驗收的共用 fixture、helper 或資料檔，CLI 使用既有 repo:path；不掃外部 repo、不猜 import 或語意關係。簽收包含這些宣告來源的內容指紋，引擎證據亦使用相同來源集合。檔案變更、刪除或失聯須給出原因，測試作者審查後再簽收；查詢本身不執行測試或改寫證據。

既有單一測試粒度保留：同檔其他頂層測試不因此失效；只有宣告同一共用來源的測試受到該檔變更影響。共用來源以檔案為單位保守追蹤，不宣稱知道哪個函式語意被改。mtime 不影響判定。

舊紀錄與封條保留，不回填不存在的共用來源。沒有宣告的部分須明示未涵蓋，不能推論沒有其他依賴。新增欄位、簽收格式相容方式及是否需要舊活動測試重新審查，先交負責人確認；本輪不變更完成算法或已安裝 wheel。

驗證應包含真實 pytest 外檔 fixture 變更、共同 helper、資料檔、來源刪除、無關測試、mtime、舊格式、文字／JSON 一致及查詢不寫入。若核定，先由測試角色建立反例，再用獨立候選 wheel 測試，不在目前完整流程途中更換管理版本。
