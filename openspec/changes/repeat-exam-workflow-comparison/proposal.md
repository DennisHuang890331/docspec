## Why

負責人要求修正後重跑同一縮小排座實驗，比較流程與文件可用性。機械回歸不能代替兩域共同進行及全新會話接手。

## What Changes

- Windows 與實際 WSL Linux 各建隔離案，固定同一 wheel、合成 CSV、任務與案外評分資料。
- 完成初版、一次容量／剩餘座位變更、未完成時的新會話接手與第二次交付。
- 獨立測試角色與實作者分離；文件定版／PDF／proof、軟體有效證據／接受／封存維持原條件。
- 保存實際 Windows 啟動與既定 EXE 網路隔離結果，以同口徑比較；README 不動。

## Capabilities

### New Capabilities
- `exam-workflow-comparison`: 同題雙平台完整流程的證據與比較契約。

無。

合成案例建置與手動驗收、案外紀錄與新驗證報告。保留前輪資料，不代稱原 README 六案通過，也不宣稱單輪比較有因果或固定用量改善。
