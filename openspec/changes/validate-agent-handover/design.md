## Context

使用者已明確核定本計畫；後續明確裁定取代舊規則，歷史保留。與先前 fix-workflow-integrity 未提交成果共存。

## Goals / Non-Goals

目標：建立正常與過時兩份隔離合成專案，各由全新 agent 根據專案紀錄接手，獨立審查預先定義的事實清單。

不新增工作摘要、stores、workset、多使用者或並行寫入能力；不自動判斷需求語意。

## Decisions

接手作業只給專案位置、執行方式與來源查核要求，不給隱藏事實答案或前文。兩個 agent 使用獨立專案；獨立 reviewer 核對預先建立的事實清單及產物。

## Risks / Trade-offs

一次實測不代表所有 agent 皆可靠。資訊缺漏與 agent 忽略資訊須分開；只修工具或流程缺陷。

## Migration Plan

不遷移治理資料，保留既有成果。

## Validation

建立合成專案、事實清單與接手作業說明；兩個無前文 agent 各自接手並記錄來源；獨立審查並修正本範圍流程缺陷；撰寫結果與工作摘要下一批建議，不新增介面。公開報告本機、跨平台及未執行界線。
