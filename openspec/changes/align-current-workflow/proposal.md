# 現行規則與提案訪談一致化

## Why

裁定已取代舊規則，但正式需求仍有強制覆述、追加交接與產品並行寫入等過時描述；提案也未提醒影響交付的使用限制。

## What Changes

整理正文與歷史取代關係；區分追溯提醒和完成條件；提案與中英協作規範先引用已有操作環境資訊，必要時才詢問。

## Capabilities

### New Capabilities

- `current-workflow-contract`：現行規則與提案訪談一致化；本 change 補充既有核定流程。

### Modified Capabilities

無；前次 fix-workflow-integrity 保留原狀。

## Impact

僅 docspec 開發工作分支，使用合成資料；不開 PR、不推送、不新增並行產品能力。
