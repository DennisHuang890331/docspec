## 已核定範圍

負責人同意縮小版考場座位實測。功能只含 CSV 匯入、排座位與座位表輸出；每位學生恰好排一次，不超過容量，同班不能前後左右相鄰，斜角除外。一份短操作手冊含一張與實際輸出一致的示意圖。保留 Windows、離線、雙擊、使用者不能安裝開發工具的訪談與交付限制。Linux 驗證不能冒充 Windows 操作驗證。

初版驗收後只追加一次「容量與剩餘座位」，在未完成時換全新會話接手。不得加入特殊考生、查詢、帳號、補考或公平報表。沒有要求隨機或強制填滿／均分兩間教室，評分不能事後追加限制。

## 案例與證據

`case_contract()` 是兩平台共同的題目、合成 CSV、負責人回答、變更、接手與評分來源。canonical JSON SHA256 防止兩平台悄悄換題；README bytes、wheel hash、初始檔案 hash 一併保存。builder 只建立全新 run，不啟動 CLI、不造命令證據、不覆寫舊 run。

專案內只放中英文 README、模糊開場 TASK 與 CSV。README 的詳細操作指南以案外 `reference/docs/user-guide.md` 提供唯讀副本，TASK 明示位置並保存 hash，避免短版 README 指向案例中不存在的指南。案外另放負責人回答、變更事件、接手說明、oracle、manifest 與 recorder；指南是可提供的公開操作資料，負責人回答與 oracle 則不可直接提供參與者。控制器依實際提問提供答案，逐字保存問答；未涵蓋事項不能臨時記為負責人已裁定需求，普通實作選擇可由實作者提出。agent 啟動資料在啟動前保存，實際會話識別碼取得後追加。接手者不帶前文；獨立審查依事前清單核對產物、真實命令及改動。

使用現有 recorder 呼叫已安裝的 artispec；沒有 DOCSPEC_AGENT 偽裝或 PYTHONPATH 注入。缺漏的 shell 紀錄另列，命令次數只依可核對的紀錄計算。準備成功、契約測試成功和完整流程通過分開記錄。

## 當前限制，尚未核定修法

本機只有 Codex 可用。`written-by`、`created-by` 目前記錄工具前綴，簽收把兩個 gpt 當同一人。不能改標 Claude、Gemini 或 user 來補通過。會話身分方案見實測準備報告；須負責人確認後才另開 change 實作。這是流程限制，與 agent 漏讀資訊分開。

## 相容性與邊界

不更動歷史實測、治理封條、舊證據或產品完成算法。不增加產品並行寫入。Windows 與 WSL Linux 各用隔離專案，角色依序操作。實作與測試分工；測試不因產生器或參與者的行為而改寫 oracle。
